## How to adapt a prompt

1. **Swap the subject, keep the craft.** Change who and what; keep the camera, light and style lines that make the shot work.
2. **Match the model's limits.** Check which durations and aspect ratios your model supports — in Vivideo the options appear when you pick a model in [manual mode](https://vivideo.ai/features/manual-mode). If the model does not support the duration written in a prompt, use the nearest one.
3. **Use a start image when accuracy matters.** Real products, real rooms and recurring characters belong in [image to video](https://vivideo.ai/features/image-to-video).
4. **Iterate one variable at a time.** If the motion is wrong, change the camera line; if the look is wrong, change the style line. Rewriting everything loses what was working.

Model-specific advice is in [../models](../models/README.md). More prompts to browse: the [Vivideo prompt library](https://vivideo.ai/prompts).
